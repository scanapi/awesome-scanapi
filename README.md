## Awesome APIs

### Payments & Banking
_APIs related to payments, digital wallets, banking services, cards, PIX, fraud detection and financial transactions._

-

### E-commerce & Marketplaces
_APIs for online stores, product catalogs, orders, checkout, inventory, logistics and marketplaces._

-

### Public Sector & Open Data
_APIs from governments or public institutions, including open data, transparency portals and civic services._

-

### Developer Platforms
_APIs provided by developer tools and platforms, such as CI/CD services, cloud tools, SDK providers and developer infrastructure._

-

### Data Providers
_APIs that expose structured data, such as market data, analytics, pricing, weather, financial data or datasets._

-

### Cloud & Infrastructure
_APIs for cloud providers, infrastructure services, observability, deployment, networking and system operations._

-

### Security & Identity
_APIs for authentication, authorization, identity management, SSO, OAuth, IAM and security services._

-

### Social & Community
_APIs for social networks, forums, messaging platforms, community tools and collaboration services._
